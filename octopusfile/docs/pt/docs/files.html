Ficheiros: copiar, mover, apagar, listar, ler, escrever

OctopusFile é uma fachada fluente sobre as operações de ficheiros do dia a dia. Todos os métodos aceitam uma String ou um Path.

javaOctopusFile octo = OctopusFile.of();

octo.write(dir.resolve("notes.txt")).text("first line\n");
octo.write(dir.resolve("notes.txt")).append("second line\n");
String text = octo.read(dir.resolve("notes.txt")).asText();

octo.copy(dir.resolve("notes.txt")).to(dir.resolve("backup/notes.txt"));      // creates "backup"
octo.move(dir.resolve("backup/notes.txt")).to(dir.resolve("archive/notes-old.txt"));

Listar#

list(...) lê os atributos de cada item uma só vez, juntamente com a listagem da pasta (uma chamada ao sistema para a pasta inteira no Windows), por isso ordenar e filtrar nunca voltam ao disco. 50 000 ficheiros são listados em cerca de 0,2 s com a cache já aquecida.

javaList<FileEntry> entries = octo.list(dir).includeDirectories().sortByName().entries();
for (FileEntry e : entries) {
    System.out.println(e.name() + (e.directory() ? "/" : "  " + e.size() + " bytes"));
}

List<Path> texts = octo.list(dir).filter(new TypeFilter("txt")).collect();
MétodoEfeito
includeDirectories()também as pastas (por omissão, só ficheiros)
includeHidden(false)ignora os itens ocultos (ficheiros começados por ponto e, no Windows, os atributos oculto/sistema)
sortByName(), sortBySize(), sortByLastModified(), sortByType(), descending()ordem
directoriesFirst(boolean)pastas antes dos ficheiros (por omissão true)
filter(FileFilter)NameFilter, SizeFilter, TypeFilter ou uma lambda sua
entries() / collect() / forEach(...)registos FileEntry / caminhos / callback

Ler e escrever#

javaocto.read(path).forEachLine(System.out::println);               // text, line by line
List<String[]> rows = octo.read("data.csv").filter(new CsvFilter().withDelimiter(";")).collect();
octo.write("out.csv").csv(rows, ";");
octo.write("blob.bin").bytes(data);

Para mais controlo, use os módulos diretamente: modules.reading (FileReader, BufferedReader, CsvReader, BinaryReader) e modules.writing (FileWriter, CsvWriter, BinaryWriter).

Apagar#

octo.delete(path) apaga de vez. Para permitir que o utilizador mude de ideias, use o Lixo.
