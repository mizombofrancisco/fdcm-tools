Mudança de nome em lote

BatchRenamer muda o nome de muitos ficheiros de uma só vez. Funciona em dois passos: um plano (novos nomes e problemas, sem tocar no disco — suficientemente rápido para ser recalculado a cada tecla premida) e a aplicação (tudo ou nada).

javaBatchRenamer.Rule rule = new BatchRenamer.Rule();
rule.template = "Holiday {n}";  // also {name}, {date}, {ext}
rule.digits = 2;
BatchRenamer.Plan plan = BatchRenamer.plan(photos, rule, null);
for (BatchRenamer.Entry e : plan.entries) {
    System.out.println(e.source.getFileName() + " -> " + e.newName + (e.problem == null ? "" : "  (" + e.problem + ")"));
}
if (!plan.hasProblems()) {
    BatchRenamer.renameAll(plan.pairs());   // all or nothing
}

Regra#

Aplicada por esta ordem, por omissão ao nome sem a extensão:

CampoEfeito
templatesubstitui o nome: {name} nome original, {n} contador (start, preenchido com zeros até digits), {date} data de modificação yyyy-MM-dd, {ext}
find, replace, regex, matchCaselocalizar e substituir, texto simples ou expressão regular (grupos $1)
prefix, suffixacrescentar texto
letterCaseKEEP, LOWER, UPPER, TITLE
includeExtensionaplicar as regras também à extensão

Problemas detetados pelo plano#

Duplicate name (dois ficheiros ficariam com o mesmo nome), Already exists (um ficheiro cujo nome não está a ser mudado já tem esse nome), Invalid characters, Empty name, Name too long, Invalid regular expression, além da sua própria verificação: o terceiro argumento de plan é uma Function<String, String> que devolve um erro ou null (por exemplo, as regras do seu sistema operativo).

Aplicação#

renameAll(pairs) usa nomes temporários apenas onde é necessário (trocas como a → b e b → a, alterações de maiúsculas/minúsculas no Windows/macOS) e desfaz todas as mudanças de nome se uma falhar. Devolve os pares aplicados, que podem ser passados de novo em sentido inverso para desfazer.

Para seleções grandes, leia os atributos uma vez com BatchRenamer.prepare(files) e chame plan(prepared, rule, check) a cada alteração: 5 000 nomes em cerca de 0,1 s.
