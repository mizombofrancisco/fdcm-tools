Análise do disco e mapa em árvore (treemap)

DiskAnalyzer percorre uma pasta uma única vez e devolve tudo o que um ecrã do tipo "o que ocupa o meu disco" precisa. Só as pastas são mantidas em memória (não um objeto por ficheiro), pelo que suporta centenas de milhares de ficheiros.

javaDiskAnalyzer.Result r = new DiskAnalyzer().top(20).analyze(folder, n -> { }, new AtomicBoolean());
System.out.println(r.root.size() + " bytes in " + r.root.fileCount() + " files");
for (DiskAnalyzer.Folder f : r.root.children()) {          // largest first
    System.out.println(f.name + "  " + f.size());
}
for (DiskAnalyzer.Category c : r.categories) {             // images, videos, music, documents, ...
    System.out.println(c.id() + "  " + c.bytes());
}
Campo de ResultConteúdo
rootárvore de pastas com o tamanho total, o tamanho dos ficheiros próprios e o número de ficheiros
largestos N maiores ficheiros
oldLargeficheiros grandes sem alterações há muito tempo (old(ageMillis, minSize), por omissão 6 meses / 50 MB)
emptyFolderspastas sem ficheiros
categoriesbytes e ficheiros por tipo (DiskAnalyzer.category(name) associa uma extensão a uma categoria)
cancelled, elapsedMilliso percurso foi interrompido / quanto tempo demorou

Os itens ocultos e pastas como node_modules, AppData, .git são ignorados por omissão (skipHidden, skipNames). A callback de progresso recebe o número de ficheiros vistos.

Disposição do mapa em árvore (treemap)#

TreemapLayout.squarify transforma tamanhos (do maior para o menor) em retângulos com áreas proporcionais aos tamanhos e formas próximas de quadrados — prontos a desenhar em qualquer toolkit de interface.

javadouble[] sizes = r.root.children().stream().mapToDouble(DiskAnalyzer.Folder::size).toArray();
List<TreemapLayout.Rect> rects = TreemapLayout.squarify(sizes, 0, 0, 800, 400);
// each Rect: x, y, w, h and index (the position in sizes)
