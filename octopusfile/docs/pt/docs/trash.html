Lixo

Um Lixo com restauro que se comporta da mesma forma no Windows, Linux e macOS. Cada item é comprimido no seu próprio ZIP e registado num índice com o caminho original, a data e os tamanhos.

javaOctopusFile octo = OctopusFile.of();

TrashEntry entry = octo.moveToTrash(file);          // compressed, indexed, restorable
System.out.println(entry.getOriginalPath() + " deleted at " + entry.getDeletedAt());

octo.restoreFromTrash(entry.getId());               // back to the same place
MétodoEfeito
listTrash()todos os itens TrashEntry
restoreFromTrash(id, otherPath)restaura noutro sítio (quando o local original está ocupado)
purgeFromTrash(id)apaga um item de vez
emptyTrash()apaga tudo de vez

O Lixo fica em ~/.octopusfile/trash (GlobalConfiguration.setTrashDirectory(...) altera-o).

Espaço: o Lixo guarda uma cópia comprimida, por isso o espaço em disco só é libertado quando o Lixo é esvaziado ou o item é eliminado de vez. Indique-o na sua interface quando oferecer ações para "libertar espaço".

Se o ficheiro original não puder ser apagado depois de arquivado (ficheiro em uso), o arquivo é removido de novo e o erro é lançado: um item nunca está no Lixo e no seu lugar ao mesmo tempo.
