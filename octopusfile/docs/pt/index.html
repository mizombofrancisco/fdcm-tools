Ficheiros

Começar depressa

Uma fachada para o dia a dia, módulos para o resto.

javaOctopusFile octo = OctopusFile.of();

octo.write(Path.of("notes.txt")).text("hello\n");
octo.copy("notes.txt").to("backup/notes.txt");

TrashEntry gone = octo.moveToTrash("backup/notes.txt");   // restorable
octo.restoreFromTrash(gone.getId());

FileIndex index = new FileIndex(home).build(null, new AtomicBoolean());
index.search(SearchQuery.of("report").extensions("pdf")).hits()
     .forEach(h -> System.out.println(h.path()));

Progresso sem esforço

O trabalho demorado passa pela fila de transferências: progresso, velocidade, tempo restante, cancelar.

javaTransfer t = TransferManager.get().copy(files, usbDrive, false, null, "USB");
TransferManager.get().addListener(x ->
        System.out.printf("%.0f%%  %,d B/s  %d s left%n",
                x.getFraction() * 100, (long) x.getSpeed(), x.getEtaSeconds()));

Regras de conceção

Com o que pode contar em todos os módulos.

  • Sem dependências externasSó o JDK: java.nio.file, java.net.http, javax.crypto, java.util.zip.
  • Rápido em pastas grandes50 000 ficheiros listados em cerca de 0,2 s; os atributos vêm com a própria listagem.
  • Nunca substitui de surpresaCópias, movimentos, extrações e ficheiros recebidos ganham nomes livres.
  • Cancelar o que demoraAtomicBoolean, BooleanSupplier ou uma Transfer que pode cancelar.
  • Exemplos testadosCada exemplo desta documentação é compilado e executado pelos testes.
