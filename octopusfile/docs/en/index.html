Quick start

One facade for the everyday work, modules for the rest.

javaOctopusFile octo = OctopusFile.of();

octo.write(Path.of("notes.txt")).text("hello\n");
octo.copy("notes.txt").to("backup/notes.txt");

TrashEntry gone = octo.moveToTrash("backup/notes.txt");   // restorable
octo.restoreFromTrash(gone.getId());

FileIndex index = new FileIndex(home).build(null, new AtomicBoolean());
index.search(SearchQuery.of("report").extensions("pdf")).hits()
     .forEach(h -> System.out.println(h.path()));

Progress for free

Long work goes through the transfer queue: progress, speed, time left, cancel.

javaTransfer t = TransferManager.get().copy(files, usbDrive, false, null, "USB");
TransferManager.get().addListener(x ->
        System.out.printf("%.0f%%  %,d B/s  %d s left%n",
                x.getFraction() * 100, (long) x.getSpeed(), x.getEtaSeconds()));
// t.cancel();

Design rules

What you can count on in every module.

  • No external dependenciesOnly the JDK: java.nio.file, java.net.http, javax.crypto, java.util.zip.
  • Fast on big folders50 000 files listed in about 0.2 s; attributes come with the listing itself.
  • Never overwrites by surpriseCopies, moves, extractions and received files get free names.
  • Cancel what takes longAtomicBoolean, BooleanSupplier or a Transfer you can cancel.
  • Examples that are testedEvery example of these docs is compiled and run by the test suite.
