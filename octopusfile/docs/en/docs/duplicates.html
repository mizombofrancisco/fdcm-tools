Duplicates and hashing

DuplicateFinder compares files by content, in three steps so that most files are never fully read: same size → same hash of the first and last 16 KiB and the size → same full hash (files up to 32 KiB are already read whole by the partial hash, so they skip the last step).

javaList<DuplicateGroup> groups = new DuplicateFinder().minSize(1024 * 1024).skipHidden(true).find(folder);
for (DuplicateGroup g : groups) {
    System.out.println(g.getFiles().size() + " copies, " + g.getWastedBytes() + " bytes can be freed");
}

find(folder, progress, cancel) reports the file being processed and stops when the AtomicBoolean is set. getWastedBytes() is the space freed by keeping one copy.

Hashing#

javaString sha256 = new FileHasher().hash(path);          // hex, streaming
boolean same = new FileHasher().matches(path, expectedHash);
String quick = new FileHasher().partialHash(path, size);   // first and last 16 KiB + size

new FileHasher("SHA-1") or any other MessageDigest algorithm also works.
