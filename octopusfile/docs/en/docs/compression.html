Compression (ZIP)

javaOctopusFile.of().compress(folder.resolve("Project"), zip);
for (ZipCompressionEngine.Entry e : ZipCompressionEngine.list(zip)) {   // central directory only, no extraction
    System.out.println(e.name() + "  " + e.size());
}
OctopusFile.of().extract(zip, folder.resolve("restored"));

ZipCompressionEngine streams with 64 KB buffers and:

  • stores already-compressed formats (jpg, mp4, zip, docx, pdf, …) without compressing them again — same size, much less CPU;
  • keeps modification dates;
  • blocks zip slip: an entry like ../../evil is rejected instead of being written outside the destination;
  • compressAll(sources, zip) puts several files and folders at the root of one archive;
  • onProgress(bytes -> …) reports progress; uncompressedSize(zip) tells how much space extraction needs.
