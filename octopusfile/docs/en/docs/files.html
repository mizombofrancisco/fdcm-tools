Files: copy, move, delete, list, read, write

OctopusFile is a fluent facade over the everyday file operations. Every method accepts a String or a Path.

javaOctopusFile octo = OctopusFile.of();

octo.write(dir.resolve("notes.txt")).text("first line\n");
octo.write(dir.resolve("notes.txt")).append("second line\n");
String text = octo.read(dir.resolve("notes.txt")).asText();

octo.copy(dir.resolve("notes.txt")).to(dir.resolve("backup/notes.txt"));      // creates "backup"
octo.move(dir.resolve("backup/notes.txt")).to(dir.resolve("archive/notes-old.txt"));

Listing#

list(...) reads the attributes of every item once, together with the directory listing (one system call for the whole folder on Windows), so sorting and filtering never go back to the disk. 50 000 files are listed in about 0.2 s on a warm cache.

javaList<FileEntry> entries = octo.list(dir).includeDirectories().sortByName().entries();
for (FileEntry e : entries) {
    System.out.println(e.name() + (e.directory() ? "/" : "  " + e.size() + " bytes"));
}

List<Path> texts = octo.list(dir).filter(new TypeFilter("txt")).collect();
MethodEffect
includeDirectories()folders too (by default only files)
includeHidden(false)skip hidden items (dot files, and the hidden/system flags on Windows)
sortByName(), sortBySize(), sortByLastModified(), sortByType(), descending()order
directoriesFirst(boolean)folders before files (default true)
filter(FileFilter)NameFilter, SizeFilter, TypeFilter or your own lambda
entries() / collect() / forEach(...)FileEntry records / paths / callback

Reading and writing#

javaocto.read(path).forEachLine(System.out::println);               // text, line by line
List<String[]> rows = octo.read("data.csv").filter(new CsvFilter().withDelimiter(";")).collect();
octo.write("out.csv").csv(rows, ";");
octo.write("blob.bin").bytes(data);

For more control use the modules directly: modules.reading (WholeFileReader, LineReader, CsvReader, BinaryReader) and modules.writing (WholeFileWriter, LineWriter, CsvWriter, BinaryWriter). Before 2.0 WholeFileReader, LineReader, WholeFileWriter and LineWriter were called FileReader, BufferedReader, FileWriter and BufferedWriter, like the java.io classes.

Deleting#

octo.delete(path) deletes for good. To let the user change their mind, use the trash.
