# FileExp

Desktop for your files (JavaFX 17): browse, search, tags, smart collections, automations, backups with versions, encrypted vault, cloud and network, Share nearby. Needs Java 17 and JavaFX 17 (lib/ next to the JAR).

*application · Ambiente de trabalho para os seus ficheiros (JavaFX 17): navegar, pesquisar, etiquetas, coleções inteligentes, automações, cópias de segurança com versões, cofre cifrado, nuvem e rede, Partilha local. Precisa de Java 17 e JavaFX 17 (lib/ ao lado do JAR).*
