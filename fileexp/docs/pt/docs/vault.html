Cofre

O cofre é uma pasta cifrada para ficheiros privados: documentos, digitalizações de cartões de identificação, palavras-passe exportadas de outros programas, etc. Abra-o em Meus Ficheiros › Pastas › Cofre.

Criar o cofre#

  1. Abra o Cofre e escolha uma palavra-passe com pelo menos 6 caracteres (uma frase longa é mais fácil de lembrar e mais difícil de adivinhar).
  2. Confirme-a.

Não há forma de recuperar o cofre sem a palavra-passe. Nem a Muendu Studio o consegue abrir. Anote a palavra-passe num local seguro.

Colocar ficheiros no cofre#

Clique com o botão direito nos ficheiros › Cofre › Mover para o cofre ou Copiar para o cofre. Com o cofre aberto, Adicionar um ficheiro… e Adicionar uma pasta… adicionam uma cópia.

  • Mover cifra o ficheiro e depois apaga o original para sempre — não vai para o Lixo, por isso não fica para trás nenhuma cópia desprotegida.
  • Copiar cifra uma cópia e mantém o original.

Usar o cofre#

  • Abrir um ficheiro: é decifrado para uma pasta privada que é esvaziada quando o cofre se fecha.
  • Guardar uma cópia… decifra um ficheiro para uma pasta à sua escolha.
  • Eliminar remove um ficheiro do cofre.
  • Fechar fecha o cofre de imediato.

O cofre fecha-se sozinho após 10 minutos sem uso e quando sai do FileExp.

Como protege os seus ficheiros#

CifraAES-256-GCM, em blocos autenticados de 1 MiB
ChaveDerivada da sua palavra-passe com PBKDF2-HMAC-SHA256, 310 000 iterações
Nomes, tamanhos e datasGuardados num índice que também é cifrado
AdulteraçãoCortar, trocar ou alterar qualquer bloco é detetado e o ficheiro é recusado
Localização~/.fileexp/vault (cifrado), ~/.fileexp/vault-open (só enquanto está aberto)
