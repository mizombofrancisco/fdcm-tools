Version history

The full, detailed list of changes is in CHANGELOG.md in the project (in Portuguese). This page summarises each version.

VersionDateHighlights
3.11.022 Nov 2026First run and system integration: a setup assistant with 10 steps (language, licences and privacy, profile, appearance, files, history, network, system, import, summary), all by keyboard; the licences of FileExp, OpenJDK, OpenJFX and JavaFX Media, in full, with acceptance; the .fexc (smart collection) and .fexr (automation rule) formats for sharing; own icons for .fexp, .fexc and .fexr; Settings › System (associations, "Open in FileExp", the fileexp command, open when you sign in); a single FileExp open at a time. 128 tests.
3.10.022 Nov 2026Power features: previous versions of a file restored from the details panel (new backup kind "Versions"), encrypted backups, folder sync between two computers with Share nearby (copy only or mirror), pause and resume in the transfers panel, and content search also in Word, Excel, PowerPoint and LibreOffice files. 106 tests.
3.9.322 Nov 2026File engine OctopusFile 2.1.1. For FileExp: a copy of a folder in the engine never replaces files without being asked, snapshot backups made in the same millisecond keep their order, and the engine can now pause transfers and sync folders between two computers (not used by FileExp yet). Share nearby is unchanged and works with 3.9.0 and later. 87 tests.
3.9.221 Nov 2026File engine OctopusFile 2.0.3, after a full audit of the engine (65 fixes). Most important: deleting permanently or moving to the Trash a folder that contains a Windows junction no longer deletes the files of the folder the junction points to; copies, backups and the Trash never go through links. Copy with Replace that is cancelled keeps the old file; mirror backups no longer delete files renamed only in letter case; the Trash and the vault are protected against several ways of losing data. 87 tests.
3.9.121 Nov 2026File engine updated to OctopusFile 2.0.1 LTS (supported until November 2028), with its fixes: the SMB password is no longer visible in the process list on Windows, and a server can be opened with the current Windows session; a folder that could be moved to the Trash only in part is never lost; vault delete and rename are safe; more exact search excerpts and batch rename. Moving a folder to another drive (USB stick) keeps working. Same data and same Share nearby protocol as 3.9.0. 87 tests.
3.9.021 Nov 2026Security: Share nearby with protocol 2 (the 6-digit code now really protects against a computer in the middle; both computers need 3.9.0, an older one is still listed and gets "update FileExp"); vault password change safe against a crash and without plain copies on the disk; a damaged key of the cloud passwords no longer stops FileExp; on macOS the SMB password is no longer visible to other users. File engine OctopusFile 1.3.0. 87 tests.
3.8.020 Nov 2026Reliability and reach: error log with "Copy report"; continuous integration on Windows and Linux; full keyboard use, screen readers and a high-contrast style; fits the screen at 125, 150 and 200 % scaling; export and import of the settings to move to another computer; My Files split into parts. 86 tests.
3.7.117 Nov 2026New "fe" icon; animated start screen; publisher Muendu Studio.
3.7.017 Nov 2026Quick look (Space), tabs, split view with drag and drop, configurable shortcuts, Share nearby. 68 tests.
3.6.017 Nov 2026Timeline, coloured tags, smart collections, encrypted vault, automations. 62 tests.
3.5.017 Nov 2026Search filters and search inside files, home index, Disk health with map and duplicates, backups, SMB servers. 53 tests.
3.4.017 Nov 2026Undo/redo for every operation, batch rename, Extract to…, automatic tests, 25× faster on folders with 50 000 files.
3.3.017 Nov 20269 languages, full properties, cloud (WebDAV and synced folders), Send to with devices, transfers panel, widget styles.
3.2.017 Nov 2026Search in the My Files bar, clean desktop, dialogs and menus inside the scene, new icon set.
3.1.017 Nov 2026My Files becomes the browser; no more explorer windows.
3.0.017 Nov 2026FileExp becomes a desktop for files: splash, top bar, widgets, Settings, NoSQL store.
2.1.017 Nov 2026No external libraries (own file engine), own window, Linux package.
2.0.017 Nov 2026Complete explorer: navigation, operations, clipboard, context menus, details, installer.

Also in 3.8.0: the file engine got a public API fully in English with a public/internal separation, and this documentation website was published in English and Portuguese.
