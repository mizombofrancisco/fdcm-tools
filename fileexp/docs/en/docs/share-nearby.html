Share nearby

Send files and folders to another computer with FileExp on the same network — at home, in the office, in a classroom — without internet, cloud or USB drive.

Turning it on#

Share nearby is off by default. Turn it on in Settings › Share nearby on both computers. There you can also choose the name others see and the folder where received files go (by default Downloads/FileExp).

Sending#

  1. Select files or folders.
  2. Right-click › Send to and choose the computer under Computers nearby.
  3. Both screens show the same 6-digit code. If the codes match, nobody is in the middle of the connection. Compare them before accepting: the code is what protects you.

Both computers need FileExp 3.9.0 or newer. A computer with an older FileExp still appears in the list, but sending to it shows "The other computer has an older version of FileExp" — update FileExp there.

Receiving#

The receiving computer shows who is sending, what, and the code, and you accept or refuse. Without an answer in 2 minutes the transfer is refused.

  • Received names are cleaned (no .., no drive letters, no Windows device names such as CON), so a sender cannot write outside the chosen folder.
  • The files must fit in the free space of the folder; otherwise the transfer stops with a clear message.
  • Nothing is overwritten: an existing name becomes "photo (2).jpg".
  • Everything appears in the timeline.

Syncing a folder (since 3.10)#

Make a folder on the other computer like a folder of this one, sending only the files that are new or changed there — the second time, almost nothing is sent.

  1. On the receiving computer, turn on Settings › Share nearby › Allow folder sync (off by default).
  2. On the sending computer, right-click a folder › Sync with and choose the computer. Computers with an older FileExp, or with folder sync off, are shown greyed out.
  3. Choose Only copy new and changed files (default) or Mirror (also delete there what is not here).
  1. The receiving computer shows who syncs which folder, the code and where it goes (by default <received files folder>/<folder name>; Choose… picks another). Compare the codes, then Accept or Decline.
Changed filesA file with the same name but another size or date is replaced by the sender's copy. This cannot be undone.
MirrorFiles and folders that the sender does not have are deleted permanently (not to the Trash). A mirror into a drive, your home folder or Desktop/Documents/Downloads/Pictures/Music/Videos is refused.
ProgressIn the transfers panel on both computers (cancel works); at the end a notification says how many files are new, updated, deleted and skipped.
TimelineThe received changes are recorded; the sender records the folder as sent.

Ordinary sending and receiving are unchanged, also with computers that have FileExp 3.9.

Security#

DiscoveryUDP broadcast on port 47821, only while the option is on
Key exchangeX25519, a new key for every transfer; the sender commits to its key (a hash) before seeing the other one, so a computer in the middle cannot search for keys that give the same code
EncryptionAES-256-GCM with a nonce counter in each direction
ConfirmationThe same 6-digit code on both screens (one chance in a million for an attacker)
LimitsAt most 4 incoming connections at a time; a silent connection is closed after 15 s

The first time you turn it on, Windows may ask whether FileExp can use the network. Allow it for private networks only.
