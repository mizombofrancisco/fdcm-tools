Backups

FileExp copies your important folders to another disk, a USB drive or a network folder. Open Settings › Backups, or right-click a folder › Back up this folder….

Four kinds of backup#

KindWhat it doesGood for
Copy the changesCopies new and changed files. Nothing is deleted in the destination.Keeping everything, even what you deleted from the original.
Exact mirrorThe destination becomes equal to the original, including deletions.An exact second copy.
Compressed (ZIP)A dated ZIP each time, keeping the last N versions.Going back to how a folder was some days ago.
Versions (since 3.10)Keeps earlier versions of every file, storing only what changed; the last N runs are kept. Can be encrypted.Getting back yesterday's version of one file.

Where the copies go#

Always to <destination>/FileExp Backup/<folder> (a Versions backup to <folder> (versions), a folder of its own). So an exact mirror never deletes other files that are on the destination disk.

Automatic backups#

Turn on Run by itself when the destination is connected in a backup job: it runs by itself when its destination disk or USB drive is plugged in (at most once per hour). You get a notification when it ends.

While a backup runs#

  • Progress and Cancel are in the transfers panel.
  • Files in use by another program are skipped without stopping the backup, and counted in the result at the end.
  • Every backup appears in the timeline.

Previous versions of a file (since 3.10)#

With a Versions backup of a folder, select a file of that folder in My Files: the details panel shows Previous versions. Show previous versions lists each version with its date and size ("same as now" marks the current content). For each one:

  • Restore a copy writes the version next to the file as name (version 2026-11-22 10.15).ext. The current file is never replaced. It goes through the transfers panel, can be undone (Ctrl+Z moves the copy to the Trash) and appears in the timeline.
  • Open shows that version without restoring it (from a temporary copy).

The backup drive has to be connected. Verify (Settings › Backups) reads the whole backup back and reports any damage.

Encrypted backups (since 3.10)#

A Versions backup can be encrypted with a password (at least 8 characters, typed twice). Contents, names, sizes and dates are encrypted with AES-256-GCM. The password is kept on this computer, encrypted with the same key as the cloud passwords, so automatic backups can run when the drive is plugged in.

There is no way to recover an encrypted backup without its password. Write it down in a safe place. On another computer, a backup imported with the settings asks for its password again.

Restoring#

The copies are ordinary files and folders (or ordinary ZIP files), so you restore by copying them back with My Files — no special tool is needed.
