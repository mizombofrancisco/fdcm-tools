Translations

FileExp is translated into 9 languages: English, Portuguese, Spanish, French, German, Italian, Russian, Japanese and Chinese. English is the source language.

How it works#

  • In Java, every visible text goes through I18n.tr("English text").
  • In FXML, texts are written in English and I18n.translate(root) translates the loaded tree.
  • Dates use the format of the chosen language.
  • The language is chosen in Settings › Language ("Same as the system" by default) and applied on restart.

The translation files#

The texts live in i18n/translations-1.txt … translations-6.txt, one text per line, the 9 languages separated by ‖:

text# English ‖ Português ‖ Español ‖ Français ‖ Deutsch ‖ Italiano ‖ Русский ‖ 日本語 ‖ 中文
Move to Trash ‖ Mover para o lixo ‖ Mover a la papelera ‖ Mettre à la corbeille ‖ In den Papierkorb ‖ Sposta nel cestino ‖ В корзину ‖ ごみ箱へ移動 ‖ 移到回收站

Adding or changing a text#

  1. Write the English text in the code: I18n.tr("Back up this folder...").
  2. Add a line with the 9 translations to one of the translations-*.txt files.
  3. Generate the table used by the app:
bashpython i18n/build_tsv.py

It writes src/ao/fileexp/i18n/strings.tsv and lists the texts of the code that still have no translation. Build again and check the screen in at least one other language.

Adding a language#

  1. Add a column to every line of the translations-*.txt files (and to the header).
  2. Add the language code to LANGS in build_tsv.py and to I18n.LANGUAGES (the list in Settings › Language is built from it).
  3. Add the words of the search filters to SearchFilter if the language should have its own (tipo:, type:…).
  4. Check long texts: German and Russian are often 30 % longer than English.

Style#

  • Portuguese is European Portuguese ("ficheiro", "Definições", "Transferências").
  • Use the same word for the same thing everywhere (Trash = Lixo, Undo = Anular).
  • Keep the {0}-style placeholders and the quotes of the English text.
